# FLURENTZA Website

This is a standard static website. Open `index.html` directly in a browser or upload the project files to a web host.

## Structure

- `index.html`: website entry point
- `styles/`: standard CSS files
- `scripts/`: standard JavaScript files
- `assets/`: supplied FLURENTZA brand and visual assets
- `public/`: reserved for future static files
- `docs/`: project documentation

No package manager, runtime, build tool, or compilation step is required.
